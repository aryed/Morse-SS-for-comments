# Writing process

Use this module for process help, substantial drafting, or submission preparation; do not impose it on a request for one proof.

For a new substantial draft, start from the key result and a minimal dependency skeleton. Make statements and definitions precise, write the decisive arguments, and fill routine details. Write or revise the introduction once the mathematical structure is stable; if the user asks for it first, comply using the available results.

In a rough prototype, explicitly labeled placeholders preserve momentum. Keep unknown constants, missing references, and proof gaps visibly unresolved. Do not pass a prototype off as a finished proof or leave hidden placeholders in a final deliverable.

Defer polishing peripheral generalizations until the core argument is sound. Include inexpensive corollaries when they materially explain the result's utility and fit the requested scope; do not turn drafting into an unrequested research program.

For final preparation, read the manuscript in order for consistency of claims, notation, and narrative; verify references and unresolved placeholders, then check prose and presentation. Follow the project's actual compilation workflow for LaTeX changes.

Do not import blanket rules about journals, deadlines, or publication strategy from a writing guide. Give those only when asked and grounded in the current situation.
